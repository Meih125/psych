## Changes

- **Added a daily login reward.** Open the app each day for gold, XP or a card.
- **Added more widget options.** New sizes up to a 4×4 that shows every quest.
- **Changed some quests' UI and wording.** Tally and Recurring got a new look.

## Fixes

- **Fixed some bugs.** Small glitches found in testing.
- **Optimized code.** Smoother and lighter on the phone.

## Updating

Install the new APK over the old one. Your progress is kept. After updating, add the new widgets from Psych › Widgets.
